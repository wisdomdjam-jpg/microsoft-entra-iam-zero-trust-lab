# Read-Only Automation Evidence

This folder contains sanitized evidence generated by the partially validated Microsoft Graph PowerShell inventory workflow.

The workflow uses delegated read-only permissions, retains Microsoft Entra Security Defaults, and makes no tenant changes.

Published outputs exclude tenant identifiers, object identifiers, application identifiers, user principal names, email addresses, request identifiers, access tokens, and personal account information.
