## Security Safeguards

The automation testing applied the following safeguards:

- Delegated interactive authentication
- Read-only Microsoft Graph permissions
- No `ReadWrite` permissions
- No client secret or certificate
- No embedded credentials
- Microsoft Entra Security Defaults retained
- Automatic Microsoft Graph disconnection
- No tenant-resource creation, modification, disabling, or deletion
- Public-safe CSV copies created before publication
- Sensitive-column review completed before upload

## Known Limitations

The tested short script does not currently validate:

- Northstar service-principal discovery
- Helpdesk Administrator and Security Reader assignment inventory
- Northstar Patient Records Portal assignment inventory
- Effective access through every possible assignment path
- Native Microsoft Entra Access Reviews
- Privileged Identity Management
- Conditional Access enforcement
- Automated remediation

These items must not be represented as implemented or successfully automated.
